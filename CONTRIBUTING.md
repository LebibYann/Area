# Contributing to the AREA project

## Commit messages

Commit messages should follow the [Conventional Commits](https://www.conventionalcommits.org/en/v1.0.0/) specification.

```
<type>(optionnal scope): <description>

[long description]

[closing issues or pull requests]
```

Use the [Conventional Commit VSCode extension](https://marketplace.visualstudio.com/items?itemName=vivaxy.vscode-conventional-commits) to help you write your commit messages.

### Scope

The scope should be the name of the package you are working on:

- `server`
- `web`
- `mobile`
- `devops`

## Issues

Issues should be used to track tasks, enhancements, and bugs for your project.

All the issues should be created from the `GitHub Project` interface.

## Branches

### Main branches

- `main`: the main branch, used for production releases
- `dev`: the development branch, used for development releases

### Feature branches

Feature branches are used to develop new features for a future release.

- The name of the feature branch should use the name of the issue you are working on.
- The feature branch should be created from the `dev` branch.

Use GitHub to create a new branch from an issue.
